## What we build here

Every new project starts the same way — wiring up the same setup, the same security, the same CI, before you write a single line that actually matters. These are our blueprints: opinionated, production-ready templates that get a greenfield project off the ground *safely* in minutes — and best-practice examples that show how to really use a tool, not just install it. Clone one, and start where the interesting work begins.

- 🚀 **Greenfield Starters** — clone-and-ship project templates, secure and CI-wired from commit one
- 🧰 **Tool Best-Practices** — reference setups showing how a specific tool is meant to be used, end to end
- 🔒 **Secure by Default** — dependency pinning, branch protection, and release automation baked in, not bolted on
- 📐 **Battle-Tested Structure** — the architecture and conventions we'd pick again, straight from real projects

Want a blueprint tailored to your stack? We'll adapt one with you — or build the one that's missing.
